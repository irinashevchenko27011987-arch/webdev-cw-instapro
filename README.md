# Instapro

MVP социальной сети для обмена фотографиями

## Первоначальная оценка

50 часов

## Фактически затраченное время

100 часов
 Удалось реализовать:
 1)Реализация поста;
 2)Реализация страницы с постами конкретного пользователя;
 3)Интеграция верстки списка постов с API;
 4)Реализация функции лайков

 Дополнительное задание:
1) Визуально отделила один пост от другого;
 2) Визуально выделила имя автора и описание. (Сливалось)
